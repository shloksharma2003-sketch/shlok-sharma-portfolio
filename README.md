# Shlok Sharma — Portfolio

A creative, single-page portfolio (pure HTML/CSS/JS — no build step).

**Effects:** interactive particle network, aurora gradient background, cursor glow, 3D tilt + spotlight cards,
typewriter roles, animated counters, scroll reveals, glitch-on-hover name, filterable certification grid.

## Deploy on GitHub Pages
1. Create a new repo (e.g. `shlok-portfolio`, or `<username>.github.io` for a root URL).
2. Upload all files in this folder (or `git init && git add . && git commit && git push`).
3. Repo → **Settings → Pages** → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. Your site goes live at `https://<username>.github.io/<repo>/` in about a minute.

## Customise
- Add your email: edit `CONTACT.email` at the top of `script.js` (the button stays hidden until set).
- Certifications live in the `CERTS` array in `script.js`.
